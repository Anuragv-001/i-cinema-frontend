# I-Cinema Frontend

Frontend-first implementation for the I-Cinema online movie ticket booking platform.

## Stack

- React
- TypeScript
- Vite
- CSS modules can be introduced later if the component set grows

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Notes

The first setup command was created manually because the local npm registry rejected `create-vite` with `SELF_SIGNED_CERT_IN_CHAIN`. If installation fails with the same error, update the npm registry certificate configuration or use a trusted registry before running `npm install`.
